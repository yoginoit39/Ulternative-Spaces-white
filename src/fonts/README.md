# Brand fonts

Drop the licensed files here and they take over automatically:

- `Kruisel-Bold.woff2`   (display / headlines)  — optional: `Kruisel-Regular.woff2`
- `Colasta-Regular.woff2` (body)                — optional: `Colasta-Medium.woff2`

Then open `src/app/fonts.ts`, set `HAVE_BRAND_FONTS = true`, and restart `next dev`.
Until then the site uses the closest free stand-ins (Outfit + Figtree).
